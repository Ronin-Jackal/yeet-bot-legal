Yeet Bot - Privacy Policy

Last updated: October 24, 2026

1. Information processed

Yeet Bot processes Discord message content to recognize its commands. When a user invokes the yeet command, the bot processes the command author's identity and the targeted member's information to generate a response.

2. Information storage

The current bot code does not intentionally save command messages or user information to a database or file. Discord and the hosting provider may independently process information under their own policies.

3. How information is used

Information is used to recognize commands, identify the target of a command, and send the requested response in Discord.

4. Sharing

The bot developer does not intentionally sell or share command data with third parties. The bot uses Discord's platform and API to operate.

5. Data retention and deletion

The current bot code does not maintain a persistent database of user command data. If future versions store information, this policy will be updated to explain the data collected, retention periods, and deletion options.

6. Contact

For privacy questions or requests, contact the bot developer through the support contact provided in the bot's profile or support server.
